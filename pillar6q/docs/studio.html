Pillar 6Q · Front-end utility studio

Projects, storyboards, and volunteer calls

Register a project repository, browse its public image assets, arrange as many storyboard frames as needed for a text segment, prepare a video prompt, then export a shareable packet.

Contributor guide · Developer requirements · Lifecycle

1 · Register or select a project

Projects can use separate public repositories on any host. Save a draft here, then request maintainer registration. A saved browser draft is not yet a shared/approved project entry.

Request project registration

Requesting registration opens a prefilled GitHub issue; submitting it requires a GitHub account. Account-free registration needs the project-owned intake service, which is not connected yet.

2 · Browse project images

For public GitHub repositories, browse images in the selected repo. For other public repository hosts, use a CORS-enabled JSON image manifest. The tool only reads; it never uploads, edits, or commits to that repository.

Register or select a project. Manifest example: {"images":[{"name":"frame-1.png","url":"https://public.example/frame-1.png"}]}.

3 · Storyboard one text segment

A segment may have start, end, and any number of intermediate keyframes. Order and describe every frame. Add frames from the repository gallery or reference a public image URL.

Only use a provider URL format that the provider documents. This encodes the prompt text; it cannot attach local image bytes.

Open provider with prompt URL

Open ChatGPT with prompt

The tool passes image URLs in the prompt when supported. Local images stay on your device: upload them manually in the selected video provider, in a repository pull request, or as public files attached to the contribution intake. Each provider has different frame-count and reference-image limits.

4 · Share a generated video and ask for volunteers

After your rendered video is stored at a public URL, prepare a volunteer call. Social buttons open each platform’s share page; they do not upload the video.

Share on X Share on Facebook Share on WhatsApp Share on LinkedIn Open Instagram

Instagram does not offer a normal web share URL for posting media. Copy the message, download/store the media in your device, then post it in the Instagram app. Follow each platform’s terms and confirm you have rights to publish the media.
