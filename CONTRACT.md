# CONTRACT overlay — khwab-seeded media books

Thin overlay on the master contract at `zistgah/governance`. It ADDS; it never relaxes.

1. **The deployment is kitab-shaped.** `index.html` at root, `js/`, `readers/`, `assets/theme/`
   copied from the template verbatim; `config/`, `content/` and `assets/` are ours. A media book
   reads in the same reader as every other book in the estate. A bare payload folder is the defect
   this clause exists to prevent.
2. **One media file serves every chapter.** Chapters carry cue points, not cut copies.
3. **A cue that ends before it starts, or runs past the end, fails the contract** — not a warning.
4. **The media travels with the book and is minted beside it.** A book whose media is elsewhere is
   not the same artifact.
5. **Endpoints are shapes, not providers.** Nothing in this repo names, defaults to or suggests any
   company's service, and at least one shipped path is local and keyless.
6. **`assets/figures` is data.** Template placeholders are swept before ours land.
7. **Nothing pushes or mints without his typed gate.**
8. **The tool's interface is read, never recalled** — a discovered verb is not a discovered signature.
