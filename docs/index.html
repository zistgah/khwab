Make something to be watched, at any length: a single image, an illustration, a diagram, an animation, a skit, a documentary, a feature, an episodic series.

A shot is a span of one reel, and the reel travels with the work. Length is not the unit — an image and a series are the same shape at different scales.

The workflow

What it asks you, in order.

These questions are this room's own. The cycling mechanism is shared with the other rooms; the questions are not, because the work is not.

  1. shotsWhere does it cut?
  2. describeWhat is on screen here?
  3. watchWhat should a viewer watch for, and why does it carry the shot?
  4. indexHow would a contents list name it?
  5. abstractWhat does the whole piece contain?
  6. posterMake a still for this shot.brings back a file

Which AI

Yours. Or none.

The cycler is not an AI provider. It puts a question on your clipboard and takes an answer back. Links below come from ai.config.json — edit it, add to it, delete from it. The list is alphabetical, not a ranking, and a server on your own machine or your own typing works exactly as well.

What it must know first

  • the reel or the images
  • its running time if it moves
  • the order a viewer meets it in

What it holds between steps

  • shot boundaries
  • stills grabbed as posters
  • the running order

What comes out

  • A book whose chapters play cued spans of one reel.

What must never stop being true

  • one image file serves every chapter that cues into it
  • a still is grabbed from the reel, never generated to look like one

How it goes wrong

  • a chapter pointing at an image that is not there
  • panels split into chapters that lose their shared source

What it needs before it will publish

  • the reel sha256
  • a poster per shot, cut from the reel itself

Run it

On your own machine.

curl -O https://raw.githubusercontent.com/zistgah/khwab/main/zcycler.py
ZCYCLER_MODEL=khwab python3 zcycler.py serve
